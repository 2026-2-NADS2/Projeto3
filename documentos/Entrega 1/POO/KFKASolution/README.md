# KFKA — Entrega 1 de POO

Protótipo em C# do sistema de acompanhamento escolar KFKA.

## Funcionalidades

- Cadastro de alunos, responsáveis, professores, turmas e disciplinas.
- Vínculo entre alunos e responsáveis e entre professores, turmas e disciplinas.
- Registro, revisão, publicação e consulta de acompanhamentos.

## Como executar

Abra `KFKASolution.slnx` no Visual Studio e execute o projeto com .NET 10.

## Estado atual

Os dados ficam em listas na memória.
